# 00 · 产品愿景

## 目标用户：四个细分群体

DoseCare不是给所有人做的"通用健康 APP"。它针对四个**真实有强烈未被满足需求**的群体：

### 1. 长期精神分裂症 / 双相情感障碍患者
- 多药联用是常态（氯氮平 + 锂盐 + 苯二氮䓬 / 抗胆碱能）
- CYP 相互作用风险高
- 急性发作期认知受损，UI 必须极简
- 治疗窗窄（氯氮平 350-600 ng/mL，锂 0.6-1.2 mmol/L，丙戊酸 50-100 μg/mL）
- 漏服、自行加量、自行停药是反复出现的问题

### 2. 难治性抑郁 / 焦虑患者
- SSRI/SNRI + 苯二氮䓬 + 助眠药 + 抗胆碱能
- 5-HT 综合征风险（SSRI + 曲马多 / MAOI / 锂盐）
- 容易叠加 OTC（中成药感冒药、止痛药）造成隐性相互作用
- 长期用药导致耐受与撤药问题

### 3. 代谢综合征共病患者
- 抗精神病药引起体重增加、糖脂异常
- 同时在用降糖药（二甲双胍、GLP-1）、降压药、降脂药
- 这些药之间也有相互作用（不是精神科药"独家"风险）
- 属于精神科群体被严重忽视的"另一半问题"

### 4. 老年精神科患者
- 抗胆碱能负荷（多药累积）→ 谵妄、跌倒、认知下降
- 肾功能减退（eGFR ↓）→ 锂盐、丙戊酸等需减量
- 联合用药数往往 > 5 种
- 服药种类多、依从性差

## 三件"只有 DoseCare 才做"的事

### ① 真实反映"代谢冲突"而不只是"重叠风险"
绝大多数用药提醒 APP 只在**时间重叠**时报警——这是浅层冲突。DoseCare 在**代谢酶层面**做配对：
- 抑制剂（A）让底物（B）血药浓度升高 → 风险
- 诱导剂（C）让底物（B）血药浓度下降 → 失效风险
- 同一 CYP 酶底物之间互相竞争 → 半衰期变化

例：**氟伏沙明**（CYP1A2 强抑制剂）+ **氯氮平** → 氯氮平 AUC 升高 5-10 倍，可致粒缺、癫痫发作、严重低血压。**这是临床真实致死场景**。

### ② 估算血药浓度曲线
- 精神科的 TDM（治疗药物监测）是真的临床实践，但**患者只被抽血那一刻知道浓度**，中间过程是黑盒
- DoseCare 用 PK 模型把"过去 24h → 现在浓度 → 下一剂预期浓度"画出来
- 让患者理解"为什么这次血药浓度在治疗窗下沿"
- 未来结合用户自己的 TDM 数据点**回算个体化的 ke/Vd**（v0.8+）

### ③ 多药并排对比
- 精神科**换药**是临床常见操作：奥氮平 → 氯氮平、SSRI 1 → SSRI 2
- 医师口头解释换药差异患者很难记住
- 用一加手机参数对比页那种并排视图，把"换药前后的 PK 差异、受体谱差异、副作用差异、相互作用差异"一次说清
- 这也是给**患者家属**最直观的科普工具

## 显式不做的事

- ❌ 不是诊断工具（不能告诉用户"你得了什么病"）
- ❌ 不是开方工具（不能告诉用户"你应该吃 X 药"）
- ❌ 不是医生替代品（任何严重警示都建议"立即联系您的医师"）
- ❌ 不做云端诊疗（联网只用于**用户主动开启的同步**和**更新药物目录**）
- ❌ 不做社交（没有"用药打卡排行榜"等）
- ❌ 不卖用户数据（不卖、也不收集，因为不在云端）

## 医学免责声明（建议放在 APP 启动时和每个警示底部）

> DoseCareDoseCare的所有计算结果（血药浓度估算、相互作用警示）**仅供参考**，基于通用群体 PK 参数和已发表的临床文献。个体差异（年龄、性别、肝肾功能、基因型、合用食物/草本）会显著影响真实数值。任何用药调整请**咨询您的精神科医师或临床药师**。
>
> 本 APP **不**作为医疗建议、医疗诊断、医疗干预的替代品。

## 核心用户旅程（Patient Journey）

```
下载 → 首次配置（症状/诊断/当前用药）→ 每日打卡 → 偶尔换药
                                                       ↓
                            收到警示（冲突/漏服/治疗窗偏离）→ 看解释
                                                  ↓
                              把信息复制/截图给医生（不联网导出）
```

```
下载（医生版，未来）→ 收到患者授权的链接/QR → 看到同一份 PK 数据 + 患者打卡
```

## 关键成功指标（暂定 v1.0 后评估）

- 漏服检测准确率（用户标记 vs 系统判定）
- 严重冲突检出率（医生审核 vs APP 报警的吻合度）
- 治疗窗维持时间占比
- 7 日 / 30 日留存
- 用户主观幸福感（量表，未来扩展）

## 未来与医院合作的可能形态

- **临床药师审核规则库**：让医院药师参与严重度分级校对
- **TDM 实验室数据接入**：把检验科报告直接导入用户档案，做个体化校准
- **科研队列**：征得同意的患者匿名 PK 数据可作为真实世界研究（RWRS）数据
- **医生端** v2.0：医师在 PC 端看到患者授权分享的 PK 曲线 + 依从性
