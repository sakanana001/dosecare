## v0.1 — MVP

**目标**：验证架构可行性，先给核心 20 个最常用精神科药一个能用版本。

### 数据
- 20 个核心药：氯氮平、奥氮平、利培酮、阿立哌唑、喹硫平、氟哌啶醇、齐拉西酮、碳酸锂、丙戊酸钠、氟西汀、舍曲林、帕罗西汀、文拉法辛、米氮平、地西泮、阿普唑唑、苯海索、劳拉西泮、奥卡西平、拉莫三嗪

### 功能
- [x] 单药 PK 曲线（一房室）
- [x] 治疗窗显示 + 状态（低于/在窗/高于）
- [x] 服药打卡（时间 + 剂量）
- [x] 提醒（AlarmManager）
- [x] 主屏极简
- [x] 加密 Room 存储
- [x] 数据备份导出（手动 JSON）

### 不做
- 多药叠加
- 冲突检测
- 对比页
- 依从性分析
- 联网
- 备份恢复

### 验收
- 给一位真实患者 1 周使用，5 个核心场景可用
- 提醒准确触发 ≥ 99%
- 加密数据库可读
- 备份可恢复

## v0.3 — 核心扩展

**目标**：规则引擎、对比页、更多药。

### 数据
- 扩展到 100 药：补齐大部分抗精神病 + 抗抑郁 + 心境稳定剂 + 苯二氮䓬
- 加入 CYP 谱完整数据

### 功能
- [x] CYP 代谢相互作用检测（基本规则）
- [x] QTc 累积风险
- [x] 抗胆碱能负荷
- [x] 5-HT 综合征风险
- [x] 治疗窗偏离报警
- [x] 多药并排对比页（一加风格）
- [x] 肾/肝剂量调整建议

### 验收
- 50 条规则测试用例通过
- 对比页视觉效果达到参考图水平
- 5 个真实冲突场景的检测率 100%

### 功能

- [x] 依从性热力图

- [x] 化验结果时间线

## v0.8 — 个体化

**目标**：从"群体 PK"到"个体 PK"。

### 功能
- [x] 酶池模型（Michaelis-Menten 多底物竞争 + 抑制剂）
- [x] TDM 数据回算 ke / Vd 个体化
- [x] CYP 基因型导入（如果有用户做基因检测）
- [x] 多个时间点 TDM 校准

### 验收

- 与 Clinical Pharmacology 专业数据库对比，10 个药误差 < 30%

## v2.0 — 多端 + 联网

**目标**：医生端 + 跨设备同步 + 联网目录更新。

### 功能
- [x] 用户账号（可选，默认不强制）
- [x] E2E 加密同步（用户密码派生密钥）
- [x] 联网 DrugCatalog 增量更新
- [x] 医生端 v1.0（PC 浏览器，看到患者授权的数据）
- [x] 患者-医生授权 token（QR 码分享）
- [x] iOS 端 v1.0

### 同步策略

- **零知识架构**：服务端只存加密 blob，看不到明文
- 用户密码 → PBKDF2/Argon2 → 加密密钥
- 任何"重置密码"会丢失云端数据（这是 E2EE 的代价）
- 强调：默认**完全不上传**任何东西，联网只用于用户主动操作

### 验收
- 跨设备登录看同一份数据
- 医生端能看到患者授权的 PK 曲线 + 警示
- 切到无网模式仍能本地使用

## 未来 v3.0+ 畅想

- **AI 警示解读**：用 LLM 把规则引擎输出转成"人话"（"你现在吃的这个组合可能让你明天早上特别困，建议晚上 8 点后不要开车"）
- **真实世界研究**：征得同意的匿名数据用于 RWRS
- **临床决策支持（CDSS）扩展**：接入 FHIR，与医院 HIS 集成
- **基因检测整合**：23andMe 等数据自动解析 CYP 多态性
- **穿戴设备**：Apple Watch / WearOS 提醒
- **药盒识别**：摄像头识别药片（警告：识别率 100% 不可能，做辅助）
- **家庭/医生多角色**：监护人可看"老人是否规律服药"（老人精神科重要）

## 风险与回退

| 风险 | 影响 | 回退策略 |
|------|------|---------|
| DrugCatalog 数据错误 | 用户信任崩塌 | 严格 review、版本控制、来源标注、免责声明 |
| 警示假阳性太多 | 用户焦虑、关闭提醒 | 默认折叠、严重度可调、加反馈机制 |
| 严重警示漏报 | 患者实际伤害 | 与临床药师合作 review、用户反馈通道 |
| KMP 抽离不彻底 | iOS 端不能复用 | 保持 domain 层纯 Kotlin 约束，PR review |
| 商业化失败 | 维护不下去 | 寻找医院/机构合作，AGPL 转让 |
| 医院合作推进困难 | 数据来源断 | 退到全部用公开数据 + 用户手动录入 |

## 发布策略

- v0.1-v0.5：内测/小范围
- v1.0：公测 + 医师社群反馈
- v1.5：正式上线
- v2.0：商业化探索（医院合作 / 公益基金支持）
